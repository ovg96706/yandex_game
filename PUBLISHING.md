# Публикация в Яндекс Играх — что загружать и какие настройки ставить

Пошаговая инструкция под Консоль разработчика (https://games.yandex.ru/console) по состоянию
документации на сентябрь 2026. Все требования к полям — из
https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft.

## 0. Коротко: что уже готово, что нужно сделать руками

| Готово | Осталось |
|---|---|
| ✅ Архив игры `dist/dungeon-keeper-idle.zip` (`npm run pack`) | ⬜ **Горизонтальное видео геймплея 16:9, MP4, ≤ 28 с** — обязательное поле, без него черновик не отправить |
| ✅ Иконка 512×512 PNG — `store-assets/icon-512x512.png` | ⬜ Переснять скриншоты в 1080×1920 (см. §5) — в `store-assets/` лежат апскейлы старых 580×1035, они проходят по формату, но мыльноваты |
| ✅ Обложка 800×470 PNG — `store-assets/cover-800x470.png` | ⬜ Скриншоты на EN/TR (сейчас все подписи на русском) |
| ✅ Скриншоты 9:16 1080×1920 — `store-assets/screenshots-mobile-portrait/` | ⬜ ≥ 2 десктопных скриншота 16:9, если включаете платформу «Десктоп» |
| ✅ Тексты карточки RU/EN/TR — §4 | ⬜ Решить вопрос с английским названием (см. §8, риск №1) |
| ✅ SDK: `/sdk.js`, `YaGames.init`, Game Ready, автоязык (2.14), GameplayAPI, пауза звука, облако | ⬜ Подключить монетизацию на вкладке «Реклама» (§6) |

## 1. Сборка архива

```bash
npm test && npm run check   # 59 тестов + импорт всех модулей
npm run pack                # → dist/dungeon-keeper-idle.zip
```

Архив соответствует п. 1.21/1.22: `index.html` в корне, без пробелов и кириллицы в именах,
2.1 МБ до сжатия (лимит 100 МБ). Внутри нет платформенного `/sdk.js` — его отдаёт сервер Яндекса
(`js/sdk.js` в архиве — это наша обёртка, так и должно быть). Phaser лежит локально в `vendor/`, CDN не используется.

## 2. Вкладка «Черновик» → блок «Общее»

### Шаг 1. Технические параметры

| Поле | Значение |
|---|---|
| Версия | `1.0.0` (любая строка; при следующих загрузках повышайте) |
| Архив | `dist/dungeon-keeper-idle.zip` |
| Поддерживаемые платформы | **Мобильные → iOS + Android** обязательно. **Десктоп** — включайте, если готовы дать ≥ 2 десктопных скриншота 16:9 (см. §5). **ТВ** — нет |
| Ориентация | **Портретная** (канвас 540×960; в альбомной SDK сам покажет заглушку «поверните экран») |

### Шаг 2. Метаданные

| Поле | Значение |
|---|---|
| Игра переведена на | **Русский, Английский, Турецкий** — ровно эти три. Модерация проверит каждый заявленный язык через SDK mocks; все три локали в игре полные (`tests/i18n-coverage.test.js`) |
| Возрастной рейтинг | **12+** — фэнтезийное насилие без крови (герои исчезают частицами), тёмный сеттинг, достижение «Первая кровь». 6+ формально защитимо («противники исчезают без следов вреда»), но 12+ безопаснее: модерация штрафует за занижение, не за завышение |
| Категории (≤ 2) | **Стратегии**, **Казуальные** |
| Теги (≤ 20) | tower defense, защита башни, мёрдж, idle, подземелье, фэнтези, пиксельная графика, боссы, прокачка, бесконечный режим |
| Ключевые слова (≤ 100 символов, нижний регистр, через запятую) | `tower defense, защита башни, мердж, подземелье, ловушки, монстры, idle, фэнтези, стратегия` |

### Шаг 3. Дополнительные параметры

| Поле | Значение |
|---|---|
| Игра использует облачные сохранения | **Включить** — игра пишет прогресс через `player.setData()` (`js/sdk.js → saveData`) |
| Отсроченная публикация | Выключено (если не планируете релиз к дате) |
| Комментарий разработчика | См. готовый текст ниже |

Комментарий разработчика (для модерации, ≤ 2048):

```
Tower defense с мёрджем на Phaser 3, портрет 540×960.
— SDK: YaGames.init() на старте, LoadingAPI.ready() после экрана загрузки, GameplayAPI.start/stop на волне, паузе и рекламе.
— Автоопределение языка (п. 2.14): environment.i18n.lang читается сразу после init; поддержаны ru/en/tr, be/kk/uk/uz → ru, остальные → en. В настройках есть ручной выбор языка — он сохраняется и перекрывает автоопределение при следующем запуске.
— Сохранения: локально + облако (player.setData) после каждого значимого действия и с троттлингом; работает и без авторизации.
— Реклама: rewarded video за награды (удвоение, прокрутка колеса, восстановление кристалла) и полноэкранная между волнами; во время показа звук и геймплей ставятся на паузу.
— Лидерборд внутриигровой (локальный), таблицы Яндекса не используются.
— Внешних ссылок и запросов к сторонним доменам нет, движок завендорен в архив.
```

## 3. Блок «Описание и продвижение»

Вкладки языков: **Русский** и **Английский** есть по умолчанию, **Турецкий** добавьте кнопкой «+».
Заполните тексты и материалы на каждой вкладке (готовые тексты — §4). Опцию «Хочу подключить
AI-описания» можно оставить включённой — тогда карточка появится и на других языках каталога,
а игра для них откроется на резервном языке (en).

## 5. Визуальные материалы и продвижение

| Поле | Требование | Что загружать |
|---|---|---|
| Иконка * | 512×512, PNG | `store-assets/icon-512x512.png` (исходник `New Folder/icon-512.png` был 511×559 — консоль такой не примет) |
| Maskable иконка | круглая безопасная зона | необязательно; можно ту же иконку — важные элементы в центре |
| Обложка * | 800×470, PNG | `store-assets/cover-800x470.png` (кроп баннера). На обложке нет текста — значит, требование «одинаковое название на всех материалах» не нарушается |
| Обложка на витрину | 1560×520, PNG/JPG | необязательно |
| Горизонтальное видео * | 16:9, MP4, высота ≥ 400 (лучше 1920×1080), ≤ 28 с, ≤ 100 МБ | **надо записать** (см. ниже) |
| Вертикальное видео | 9:16, MP4, ≤ 28 с | желательно — портретной игре оно к лицу |
| Скриншоты * | мобильные портретные ровно 9:16, длинная сторона 1280–2560, JPEG/PNG-24, ≥ 2 шт.; для «Десктоп» отдельно ≥ 2 альбомных 16:9 | `store-assets/screenshots-mobile-portrait/screenshot-01…09.jpg` |

### Как переснять скриншоты в нормальном качестве

1. `npm run serve`, откройте `http://localhost:3000/?lang=ru` (для EN/TR — `?lang=en`, `?lang=tr`).
2. Chrome → DevTools → режим устройства (Ctrl+Shift+M) → размер **540×960**, DPR **2**.
3. Ctrl+Shift+P → «Capture screenshot» → получите ровно **1080×1920**.
4. Десктопные (если нужны): игра портретная, поэтому чтобы геймплей занимал ≥ 70 % кадра (п. 5.1.1.2),
   снимайте 16:9-фрагмент доски крупным планом (например, DPR 3 и кроп 1920×1080 из центра), а не весь экран с чёрными полями.

### Как сделать горизонтальное видео из вертикальной записи

Запишите 20–25 секунд боя с боссом и мёрджем (OBS / Win+G / QuickTime), затем:

```bash
ffmpeg -i запись.mp4 -t 28 -filter_complex \
  "[0:v]scale=1920:1080,boxblur=20:5[bg];[0:v]scale=-2:1080[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2" \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 128k video-16x9.mp4
```

Получится 1920×1080: игра по центру, по бокам размытая копия кадра. Ту же запись без обработки (≤ 28 с) загрузите как вертикальное видео.

## 6. Реклама и выплаты

1. Вкладка **Реклама** → **Подключить монетизацию**. Для юрлиц/ИП из РФ — «Единая лицензионная схема» в профиле Консоли; остальным — регистрация в РСЯ. **Логин РСЯ должен совпадать с логином аккаунта Яндекс Игр**, иначе монетизация не подключится.
2. Рекламные блоки создаются автоматически после публикации; в черновике показывается тестовая реклама Яндекса — на ней и проверяйте rewarded/fullscreen.
3. Sticky-баннер в игре не используется — соответствующую опцию в черновике не включайте.

## 7. Проверка перед отправкой на модерацию

Откройте черновик кнопкой **«Открыть с debug-панелью»** (или добавьте `?debug-mode=16` к адресу игры) и пройдитесь по списку:

- [ ] Лоадер показывает **IT** (`Is loader: true`).
- [ ] Индикатор Game Ready становится зелёным на экране меню (`The game called ready after … ms`).
- [ ] Индикатор **文** зелёный **ещё на экране загрузки**, а не после нажатия «Играть» (п. 2.14).
- [ ] **SDK mocks ⚒️ → язык**: откройте игру на **Ru**, **En**, **Tr** — весь интерфейс, включая экран загрузки, переключается. Перед проверкой очистите localStorage (ручной выбор языка в настройках перекрывает мок — так и задумано, документация это допускает).
- [ ] Кнопка 🎮: зелёная во время волны, красная в меню/паузе/рекламе (GameplayAPI).
- [ ] Кнопка ▶️/⏸️: при паузе платформы звук и волна останавливаются, при возврате — продолжаются.
- [ ] Rewarded: награда выдаётся только после `onRewarded`; закрытие ролика без просмотра награды не даёт. Fullscreen: между волнами, звук во время показа выключен.
- [ ] Сворачивание вкладки — звук замолкает (п. 1.3).
- [ ] Правый клик / выделение текста / зум жестами не срабатывают (п. 1.6, 1.10).
- [ ] ☁️ **Clear cloud data** → игра стартует «как в первый раз» без ошибок в консоли.

Затем на вкладке «Черновик» — **Отправить на модерацию**. Результат придёт на почту аккаунта и появится в Консоли; при отклонении в письме будут номера пунктов Требований.

## 8. Риски, о которых лучше знать заранее

1. **Название «Dungeon Keeper» — зарегистрированный товарный знак Electronic Arts** (Dungeon Keeper™). Английское название с ним могут отклонить за нарушение прав третьих лиц, а с ним и заголовок в самой игре (`menu_title`, `boot_title` в `js/i18n.js`, `<title>` в `index.html`). Русское «Хранитель Подземелья» — прямой перевод того же тайтла; риск ниже, но проверьте уникальность в каталоге (п. 5.12): найдите название в поиске https://yandex.ru/games. Если решите переименовать — это 6 строк в i18n + index.html, и обложка не пострадает (на ней нет текста).
2. **Горизонтальное видео обязательно** — без него форма не отправится.
3. **Скриншоты в `store-assets/` — апскейл со старых 580×1035** (старый билд, только русский). Формат пройдёт, но лучше переснять по §5 в трёх языках: скриншоты с русским текстом на EN/TR-вкладках модерация может счесть непереведёнными материалами.
4. **Десктоп + 70 % геймплея на скриншоте** — портретную игру на 16:9 придётся снимать фрагментом доски (§5), иначе проще стартовать только с мобильными платформами и добавить десктоп следующей версией.
5. После публикации любое изменение названия/иконки/обложки отправляет игру на повторную модерацию.
