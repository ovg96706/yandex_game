# Хранитель Подземелья (Dungeon Keeper Idle)

Браузерная idle/tower-defense игра для **Яндекс Игр**. Phaser 3.80.1 завендорен в архив, внешние CDN не используются. SDK платформы подключается как `/sdk.js` — файл скачивать и класть в ZIP нельзя.

Игрок — Хранитель Кристалла Бездны: расставляет ловушки и монстров, отражает волны героев, мёрджит защиту и развивает мета-прогресс.

## Публикация в Яндекс Игры

```bash
npm test
npm run check
npm run pack
```

Готовый архив: `dist/dungeon-keeper-idle.zip`

Полная инструкция по публикации (поля Консоли, готовые тексты RU/EN/TR, материалы, чек-лист модерации) — **[PUBLISHING.md](PUBLISHING.md)**; готовые иконка/обложка/скриншоты — `store-assets/`.

В Консоли разработчика (https://games.yandex.ru/console):

1. Создайте черновик → поле **Архив** → загрузите ZIP.
2. Ориентация: **portrait**. Платформы: desktop + mobile.
3. Языки: русский, английский, турецкий. Включите автоопределение языка.
4. Включите **игра использует облачные сохранения**.
5. Иконки и скриншоты лежат в `New Folder/` (для карточки каталога, в архив не входят).
6. Проверьте черновик с `?debug-mode=16`: лоадер должен показать **IT**, индикатор 文 стать зелёным ещё на экране загрузки, в консоли — `Initialized`. Затем в «SDK mocks ⚒️» откройте игру на ru, en и tr — все тексты должны переключиться.

SDK в архиве **нет**: на сервере Яндекса `/sdk.js` отдаёт платформа. Локально заглушку подставляет `npm run serve`.

## Локальный запуск

```bash
npm run serve
```

Открывается `http://0.0.0.0:3000/`. Движок грузится из `vendor/phaser.min.js`, без интернета. Реклама и облако в этом режиме недоступны — награды за видео не выдаются.

Проверка автоопределения языка (п. 2.14) локально — параметр `?lang=<код>` поднимает мок `YaGames`
с `environment.i18n.lang`, как выпадающий список языков в «SDK mocks ⚒️» debug-панели:

```
http://localhost:3000/?lang=tr   # турецкий
http://localhost:3000/?lang=en   # английский
http://localhost:3000/?lang=kk   # казахский → резервный ru
http://localhost:3000/?lang=de   # немецкий → резервный en
```

В консоли браузера заглушка пишет, был ли прочитан `environment.i18n.lang` **до** `LoadingAPI.ready()`
(это и есть зелёный индикатор 文). Если в настройках игры язык уже выбирали вручную, он перекроет
мок — очистите localStorage, как модерация чистит кеш.

Для проверки настоящего SDK: `@yandex-games/sdk-dev-proxy` и черновик в Консоли.

## Что внутри архива

```
index.html                 — точка входа (локальный Phaser + /sdk.js)
vendor/phaser.min.js       — Phaser 3.80.1 (MIT), без CDN
assets/icon-256.png
js/                        — чистый ESM, без сборщика
  config.js                — баланс и чистая логика
  saveManager.js           — валидация/миграция сейва
  sdk.js                   — обёртка YaGames (retry, GameplayAPI, пауза)
  adManager.js             — очередь рекламы
  audio.js                 — Web Audio, стоп при потере фокуса
  scenes/                  — Boot … Settings
```

## Ключевые механики

- Доска 5×8, комбо «ловушка + монстр», дракон 2×2.
- Монстры имеют HP и гибнут от героев.
- Лучник бьёт с дистанции, маг рассеивает ловушки, вор крадёт золото при прорыве, архимаг проклинает монстров, король зовёт подкрепления.
- Огонь — DoT 4 сек, лёд останавливает и замедляет на 3 сек, некромант поднимает павших.
- 5 сюжетных глав, режим Бездна, задания, таланты, бестиарий.
- `LoadingAPI.ready()` на входе в меню; `GameplayAPI.start/stop` на волне, рекламе и скрытии вкладки.
- Реклама: try/catch + таймаут 45 с; без SDK награда не выдаётся.
- Лидерборд локальный (клиентский score на платформу не отправляется).

## Требования платформы, которые закрыты в коде

| Пункт | Как сделано |
|---|---|
| 1.1 / 1.19 SDK | `<script src="/sdk.js">`, `YaGames.init()` в BootScene |
| 1.3 звук при потере фокуса | `audio.suspendAll()` на `visibilitychange`, `blur`, `game_api_pause` |
| 1.6.1.8 / 1.6.2.7 контекстное меню | `preventDefault` + CSS `user-select: none` |
| 1.10 нет системного скролла | `overflow: hidden`, `overscroll-behavior: none` |
| 1.19.2 Game Ready | `SDK.ready()` → `LoadingAPI.ready()` перед меню |
| 1.21 / 1.22 архив | `npm run pack`: index.html в корне, без пробелов/кириллицы, < 100 МБ |
| 1.7 нет S3 URL | внешних абсолютных URL нет |
| 2.14 автоязык | `environment.i18n.lang` читается сразу после `YaGames.init()` (до `getPlayer`/облака) в BootScene; экран загрузки перерисовывается на языке платформы до `ready()`; резерв: be/kk/uk/uz → ru, остальные → en; ручной выбор в настройках перекрывает платформу |

## Команды

```bash
npm test        # node --test
npm run check   # синтаксис + ESM-импорт модулей
npm run serve   # локальный превью-сервер
npm run pack    # ZIP для Консоли
```

CI-шаблон: `ci/github-actions.yml` (скопируйте в `.github/workflows/ci.yml` токеном с правом `workflows`).

Сейв: `SAVE_VERSION` в `saveManager.js`. Любое изменение формата — bump версии и `validateSave`.
