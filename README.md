# Хранитель Подземелья (Dungeon Keeper Idle)

Браузерная idle/tower-defense игра для платформы Yandex Games (Phaser 3, чистый ESM, без сборочного контура).

Игрок — Хранитель Кристалла Бездны: расставляет ловушки и монстров, отражает волны «героев»,
мёрджит защиту до 5-го уровня и развивает мета-прогресс (магазин, таланты, задания, бестиарий).

## Структура

```
dungeon_keeper_mvp/
  index.html          — точка входа (Yandex SDK v2 + Phaser CDN)
  js/
    config.js         — весь баланс и чистая игровая логика (юниты, герои, волны,
                        таланты, задания, главы, офлайн-доход, валидация доски)
    saveManager.js    — валидация/миграция сейва (SAVE_VERSION), конфликт cloud/local
    sdk.js            — тонкая обёртка Yandex SDK (cloud-save, реклама, таймауты)
    adManager.js      — очередь рекламы, пауза/возобновление сцены
    quests.js         — ежедневные/еженедельные задания (baseline-подход)
    achievements.js   — 53 достижения
    audio.js          — Web Audio (разблокировка жестом, процедурная музыка)
    graphics.js       — процедурные текстуры и эффекты
    scenes/           — Boot, Preloader, Menu, Game/Endless, Shop, Talents, Quests,
                        Daily, Wheel, Achievements, Bestiary, Leaderboard, Settings
tools/check.mjs       — ESM-импорт всех модулей (ловит то, что пропускает node --check)
tests/                — node --test (экономика, сейвы, реклама, квесты, i18n, бой)
```

## Ключевые механики

- **Доска 5×8** с комбо-слотами: в одной клетке могут стоять ловушка **и** монстр.
  Дракон занимает блок **2×2**.
- **Монстры имеют HP** и гибнут от атак героев; при победе в волне погибшие монстры
  не восстанавливаются (прерванная волна откатывается — см. ниже).
- **Герои сражаются**: при приближении к монстру герой останавливается и атакует.
  Целитель не атакует. Боссы бьют сильнее.
- **Паладин**: щит блокирует первые 3 эффекта **ловушек** (включая телепорт),
  но не атаки монстров. Яд/замедление не накладываются через блок.
- **Главы кампании** (5 шт., волны 1/11/26/51/76): сюжетное интро один раз,
  флаг `seenChapters` в сейве.
- **Бездна** (endless): отдельный забег с локальной экономикой, награда — в конце.
- **Анти-эксплойт волны**: снимок сейва на старте волны; скрытие вкладки/смена сцены
  откатывает недобранные награды и восстанавливает доску.

## Команды

```bash
npm test        # все тесты (node --test)
npm run check   # node --check + ESM-импорт всех модулей
```

Сейв версионируется (`SAVE_VERSION` в `saveManager.js`); любое изменение формата
требует bump версии и обновления `validateSave`. Ненадёжные данные (localStorage/облако)
всегда проходят через `validateSave`: диапазоны, доска, апгрейды, квесты, главы.

## Релизный чек-лист (Yandex Games)

1. `npm test && npm run check && git diff --check` — зелёные.
2. **Phaser CDN**: версия закреплена на `phaser@3.80.1`. Перед релизом проверить целостность
   и при возможности добавить SRI:
   ```bash
   curl -s https://cdn.jsdelivr.net/npm/phaser@3.80.1/dist/phaser.min.js \
     | openssl dgst -sha384 -binary | openssl base64 -A
   ```
   Полученный хэш добавить в `index.html`: `integrity="sha384-..." crossorigin="anonymous"`.
   Альтернатива — завендорить `phaser.min.js` в репозиторий и ссылаться локально.
   (В текущем контуре разработки сети нет, поэтому хэш вычисляется на релизной машине —
   поддельный/устаревший хэш заблокирует загрузку движка.)
3. Yandex SDK подключается только с `https://yandex.ru/games/sdk/v2` (требование платформы).
4. Ручной прогон в черновике Yandex Games: rewarded/fullscreen-реклама, облачные сейвы,
   авторизация. В локальном режиме реклама недоступна по дизайну — награды не выдаются.
5. Лидерборд — **локальный** (клиентский score нельзя считать доверенным); глобальный
   таблица лидеров возможна только с серверной верификацией — до её появления не включаем.
